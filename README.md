# EduCraft — Платформа и конструктор онлайн-школы (Python + Flask + SQLite)

## Возможности
- Витрина курсов с фильтрацией по категориям, личный кабинет ученика, регистрация и авторизация.
- Защищённый плеер уроков: проверка прав доступа на сервере Python, водяные знаки, защита от копирования и печати.
- Поддержка форматов уроков: текстовый конспект, защищённый **PDF** (постраничный рендеринг через PDF.js), вставка **HTML-файлов** (интерактивные страницы/тесты в изолированном iframe) и **песочница кода (HTML/CSS/JS)**.
- Визуальный конструктор школы для администратора.

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python app.py
   ```
3. Откройте в браузере: `http://127.0.0.1:5000`
